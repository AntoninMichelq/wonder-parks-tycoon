Installer le jeu

Sur Android

  1. Touche Télécharger pour Android depuis ton téléphone.
  2. Ouvre le fichier WonderParksTycoon.apk dans tes téléchargements.
  3. Si Android le demande, autorise ton navigateur à installer des applications, puis touche « Installer ».

Le jeu n'est pas encore sur le Play Store, c'est pour ça qu'Android pose la question.

Sur Windows

  1. Clique sur Télécharger pour Windows.
  2. Fais un clic droit sur le fichier .zip, puis « Extraire tout ».
  3. Lance WonderParksTycoon.exe. Si Windows affiche « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis « Exécuter quand même ».

Windows affiche cet avertissement pour tous les jeux indépendants qui ne sont pas signés.

Questions fréquentes

Le jeu est-il gratuit ?

Oui. Tout ce qui fait avancer le parc s'obtient en jouant : gemmes, caisses et Mascotte dorée se gagnent avec les objectifs, les succès, le cadeau du jour et le Pass gratuit.

Faut-il une connexion internet ?

Non. Ta partie est enregistrée sur ton appareil. La connexion ne sert qu'au classement mondial, avec Google Play Jeux sur Android.

Mon parc avance-t-il quand le jeu est fermé ?

Oui, tant que tes enclos ont un manager. À ton retour, Gus te donne ce qu'ils ont gagné.

Comment mettre à jour le jeu ?

Télécharge la nouvelle version ici et installe-la par-dessus l'ancienne. Ta partie est gardée.
